# HSV YOLO Labeler

카메라 또는 영상에서 HSV 색상 범위로 객체를 검출하고 Ultralytics YOLO11 데이터셋을 만드는 PyQt5 도구입니다. 라벨링부터 검수, 오류 수정, 클래스 균형 분할, 데이터 증강까지 한 프로그램에서 처리합니다. ROS는 필요하지 않습니다.

## 빠른 실행

### Linux

```bash
git pull
./run.sh
```

`run.sh`는 저장소 내부에 `.venv`를 만들고 의존성을 자동 설치합니다. 한글과 공백이 포함된 경로에서도 Qt 플러그인을 찾도록 구성되어 있습니다.

실행 환경을 초기화하거나 완전히 다시 설치하려면:

```bash
./remove_env.sh
./run.sh
```

`remove_env.sh`는 `.venv`, Python 캐시, 임시 Qt 플러그인 링크만 제거합니다. 소스 코드와 데이터셋은 유지됩니다. 확인 질문 없이 실행하려면 `./remove_env.sh --yes`를 사용합니다.

### Windows

Python 3.10 이상을 설치한 뒤 실행합니다.

```bat
run.bat
```

### 직접 실행

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python hsv_yolo_labeler.py
```

다른 카메라 번호를 사용하려면:

```bash
./run.sh --camera 1
```

## 권장 작업 순서

```text
HSV 설정 및 라벨링
→ 라벨 검수와 오류 수정
→ Train / Valid / Test 클래스 균형 분할
→ Train 데이터 증강
→ YOLO11 학습
```

## 실시간 카메라

- 카메라 번호 선택 및 실시간 전환
- Hue 원형 범위와 S/V 범위 실시간 조절
- `Start H > End H`일 때 빨간색처럼 `179 → 0` 경계를 자동 처리
- 최소 면적과 노이즈 제거 설정
- 큰 박스 안의 작은 박스 제거 옵션
- 현재 프레임의 바운딩 박스 수 표시
- 설정한 프레임 간격으로 이미지와 라벨 자동 저장

단축키:

- `Space`: 자동 저장 시작/종료
- `S`: 현재 프레임 수동 저장
- `Q` 또는 `Esc`: 종료

## 영상 라벨링

- MP4, AVI, MOV, MKV, WEBM, M4V 파일 선택 또는 드래그앤드롭
- 현재 HSV 설정으로 저장 없는 미리보기
- 확인 후 영상을 처음부터 다시 처리하여 라벨 저장
- `0.5×`, `1×`, `2×` 배속
- 재생/일시정지와 타임라인 탐색
- `←`, `→`: 5초 전후 이동
- `Space`: 재생/일시정지
- 영상 종료 후 `Space`: 처음부터 미리보기 재생
- 90° 단위 회전 — 미리보기, 저장 이미지, 라벨 좌표에 동일 적용
- 미리보기에서 현재 클래스의 목표 객체 수가 다르면 자동 일시정지
- 실제 영상 저장은 목표 객체 수와 관계없이 끝까지 진행

## 데이터셋과 클래스

- 데이터셋 폴더 선택 또는 생성
- 기존 `data.yaml`에서 클래스 이름 자동 로드
- 클래스 추가, 이름 변경, 삭제
- 이름 변경 시 동일한 클래스가 있으면 확인 후 병합
- 병합과 삭제 시 Train/Valid/Test의 클래스 ID 자동 재정렬
- 이미지와 라벨을 YOLO11 형식으로 저장

## 검수와 오류 수정

클래스 통계:

- 전체 및 클래스별 바운딩 박스 수 표시
- 전체 검수 또는 특정 클래스만 검수
- 방향키로 저장 이미지를 연속 탐색
- 이미지의 모든 박스를 선택한 클래스로 변경

오류 검사:

- 이미지와 라벨 파일의 쌍 누락
- 같은 이름의 중복 이미지
- 손상되거나 읽을 수 없는 이미지
- 잘못된 YOLO 라벨 열 개수와 숫자 형식
- 존재하지 않는 클래스 ID
- NaN, 무한대, 0 이하의 박스 크기
- 0~1 정규화 범위 또는 이미지 경계를 벗어난 박스
- 검사 실행 중 버튼 잠금으로 중복 실행 방지

좌표 오류는 `박스 수정`에서 고칠 수 있습니다.

- 네 꼭짓점을 마우스로 드래그
- 왼쪽, 오른쪽, 위, 아래 벽을 각각 1px 안쪽으로 이동
- 모든 방향을 한 번에 1px 축소
- 수정한 라벨 행만 즉시 재검사

빈 라벨 파일은 객체가 없는 정상 배경 이미지로 처리합니다. 이미지에 대응하는 라벨 파일 자체가 없으면 오류입니다.

## 클래스 균형 분할

- Train/Valid/Test 비율 설정 — 기본 `70 / 20 / 10`
- 랜덤 시드 설정
- 실행 전 split별 이미지 수와 클래스별 박스 수 미리보기
- 다중 클래스 이미지를 포함해 각 클래스 분포가 가능한 한 비슷해지도록 배정
- 이미지와 라벨을 항상 쌍으로 이동
- 이동 오류 발생 시 복구용 임시 파일 보존

클래스 수가 적거나 여러 클래스가 항상 같은 이미지에 나타나면 정확한 비율 일치는 불가능할 수 있습니다.

## 데이터 증강

원본 데이터셋을 수정하지 않고 같은 위치에 `<데이터셋명>_aug`를 새로 만듭니다. 같은 이름이 있으면 `_aug_2`, `_aug_3` 순으로 생성합니다.

- Train: 원본 유지 + 증강본 추가
- Valid/Test: 변경 없이 복사
- 빈 라벨 배경 이미지 증강 제외 옵션 — 기본 활성화
- 원본당 증강본 수 — 기본 3장
- 랜덤 시드, 예상 생성 장수, 진행률, 취소
- 작업 중 임시 폴더 사용
- 취소 시 임시 결과 삭제, 오류 시 복구를 위해 보존

지원 효과:

- Saturation — 기본 `-25% ~ +25%`
- Brightness — 기본 `-15% ~ +15%`
- Exposure — 기본 `-10% ~ +10%`
- Blur — 기본 `0 ~ 2.5px`
- Noise — 기본 `0 ~ 0.1%`

각 효과 버튼은 최소 적용, 원본, 최대 적용 이미지를 나란히 보여줍니다. 슬라이더로 범위를 조절할 수 있으며 최소값이 최대값보다 크면 적용을 차단합니다. 증강 탭의 오른쪽 화면에서는 모든 효과가 합쳐진 결과를 실시간으로 확인할 수 있습니다.

## YOLO11 데이터셋 구조

```text
dataset/
├── data.yaml
├── train/
│   ├── images/
│   └── labels/
├── valid/
│   ├── images/
│   └── labels/
└── test/
    ├── images/
    └── labels/
```

`data.yaml`:

```yaml
path: .
train: train/images
val: valid/images
test: test/images

nc: 1
names:
  0: 'object'
```

YOLO 라벨 한 줄:

```text
class_id x_center y_center width height
```

좌표는 모두 0~1 범위로 정규화됩니다. `path: .`을 사용하므로 데이터셋 폴더를 이동해도 절대경로를 수정할 필요가 없습니다.

## 주요 파일

```text
hsv_yolo_labeler.py  # 애플리케이션
requirements.txt     # Python 의존성

```
