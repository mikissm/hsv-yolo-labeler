# 실시간 HSV → YOLO 바운딩 박스

기존 `detection_hsv_tool`과 비슷한 Qt UI에서 카메라 영상의 HSV 색 범위를
조정하고, 바운딩 박스가 포함된 YOLO 형식 라벨을 저장합니다.

## 설치 및 실행

### Linux

저장소 루트에서 pull한 뒤 바로 실행합니다.

```bash
git pull
./run.sh
```

`run.sh`는 프로젝트 내부의 `.venv`를 자동으로 만들고 필요한 패키지를 설치합니다.
이후 실행부터는 설치 과정 없이 바로 프로그램이 열립니다.

### Windows

Python 3.10 이상을 설치한 뒤 프로젝트 폴더의 `run.bat`을 실행합니다.

```bat
run.bat
```

### 직접 실행

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python hsv_yolo_labeler.py
```

GUI에는 PyQt5를 사용하고 OpenCV는 Qt가 포함되지 않은 headless 빌드를 사용하므로,
두 패키지의 `xcb` 플러그인 충돌을 피할 수 있습니다. ROS는 필요하지 않습니다.

다른 카메라나 클래스 번호를 쓰려면:

```bash
python hsv_yolo_labeler.py --camera 1 --class-id 2 --min-area 1000
```

## 사용법

- 왼쪽 패널에서 Hue, Saturation, Value 범위를 조절합니다.
- 가운데 마스크와 오른쪽 원본/박스 영상을 비교합니다.
- `Start H > End H`이면 빨간색처럼 Hue의 179→0 경계를 자동 포함합니다.
- 화면에서 카메라 번호와 YOLO Class ID를 바꿀 수 있습니다.
- `데이터셋 > 폴더 선택 / 생성`에서 저장 루트를 정합니다.
- `클래스 추가`로 이름을 등록하면 현재 클래스 번호가 라벨에 기록됩니다.
- 자동 저장을 켜면 지정한 프레임 간격마다 이미지와 라벨을 저장합니다.
- `Space`: 자동 저장 시작/종료
- `저장 라벨 검수`에서 이미지별 박스와 클래스 이름을 확인하고, 현재 이미지의
  모든 박스 클래스를 선택한 클래스로 다시 지정할 수 있습니다.
- 영상 파일을 창에 드래그앤드롭하거나 `영상 선택`으로 불러올 수 있습니다.
- `영상 미리보기 실행`은 현재 HSV/박스 설정을 저장 없이 확인합니다.
- 확인 후 `현재 설정으로 영상 라벨링 저장`을 누르면 영상을 처음부터 다시 읽어
  지정한 프레임 간격대로 YOLO11 이미지와 라벨을 저장합니다.
- 영상 모드에서 `Space`는 재생/일시정지, `←`와 `→`는 5초 전후 이동입니다.
- 영상이 끝난 뒤 `Space`를 누르면 처음부터 미리보기를 다시 시작합니다.
- 하단 배속 메뉴에서 `0.5×`, `1×`, `2×` 재생 속도를 선택할 수 있습니다.
- 하단 타임라인을 드래그해 원하는 위치로 이동할 수 있고 현재/전체 시간이 표시됩니다.
- `90° 회전`은 미리보기와 저장 이미지/라벨에 함께 적용됩니다.
- `data.yaml 생성`은 현재 클래스 목록을 포함한 Ultralytics YOLO11 설정을 만듭니다.
- 기존 데이터셋 폴더를 선택하면 `data.yaml`의 클래스 이름을 자동으로 불러옵니다.
- 클래스 이름 변경과 삭제를 지원하며, 같은 이름으로 바꾸면 확인 후 두 클래스의
  라벨을 병합하고 전체 클래스 ID를 다시 정렬합니다.
- `현재 데이터 정보`의 표에서 전체 및 클래스별 바운딩 박스 수를 한눈에 확인하고,
  각 행의 버튼으로 해당 클래스 검수를 바로 시작할 수 있습니다.
- 검수 창의 `검수 범위`에서 전체 데이터 또는 특정 클래스만 골라 확인할 수 있습니다.
- `S`: 현재 원본 프레임과 박스 라벨 저장
- `Q` 또는 `Esc`: 종료

저장 결과는 다음과 같습니다.

```text
dataset/
├── data.yaml
├── train/
│   ├── images/frame_....jpg
│   └── labels/frame_....txt
├── valid/
│   ├── images/
│   └── labels/
└── test/
    ├── images/
    └── labels/
```

라벨 한 줄은 YOLO 표준 형식인
`class_id x_center y_center width height`이며 좌표는 0~1로 정규화됩니다.

`data.yaml`의 dataset 경로는 `path: .`으로 기록되므로 dataset 폴더 전체를 다른
위치로 이동해도 절대경로를 수정할 필요가 없습니다.

빨간색 기본 범위는 `H 170 → 10`이며 Hue 경계를 넘는 두 구간을 자동으로 합칩니다.
